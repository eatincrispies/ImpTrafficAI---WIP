## Overview

This plugin is designed to tweak and enhance the traffic AI logic in Need for Speed: Carbon. Existing code remains available for reference, but active development is on hold.

## What This Mod Fixes & Aims to Do

NFS Carbon's original traffic AI suffered from several major issues due to EA rushing the game to release before it was fully finished. This mod tackles those shortcomings with the primary purpose of making the traffic **less stupid**. 

### Key Fixes & Improvements

* **Reckless Swerving:** Prevents traffic cars from randomly and carelessly turning into your lane without notice, which frequently causes unavoidable collisions.
* **Wall Collisions & Sticking:** Addresses issues where traffic cars constantly hit walls, get stuck, or act completely clueless and unresponsive.
* **Inspirations:** Takes notes and references from *Need for Speed: Undercover*'s traffic AI implementation to guide the improvements.
